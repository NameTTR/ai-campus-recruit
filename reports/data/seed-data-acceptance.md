## 复现与修复

| 问题 | 复现 | 修复与验证 |
| --- | --- | --- |
| 公司展示为账号编号 | 通过企业 API 创建岗位后查看学生岗位列表 | 增加可选 `companyName`；展示名不参与归属判断，旧请求兼容；新增伪造展示名、持久化及越权回归 |
| 可行日程被判为同日超限 | 每周 4 小时、周一三五、每日 90 分钟 | 按完整分钟分段分配，保留原任务最终段 ID、依赖、引用和验收内容；容量不足时拒绝保存；14 项专门回归 |
| 重规划丢失任务分段 | 分段计划生成预览并确认，或省略新日程参数 | 沿用原日程，确认保留预览全部分段；已完成任务、日期和成果保留 |
| 小任务被显示成整小时 | 查看 30、90 分钟任务及周复盘 | 四处任务展示优先使用分钟，复盘按真实分钟汇总；旧小时字段回退兼容，3 项前端回归 |

修复没有增加基础设施，也没有更换中国 Docker、Maven、npm 镜像。

`ai-service` 和 `delivery-service`，保留 MySQL、MinIO 等存储卷。

```powershell
node scripts/seed-realistic-data.cjs --verify-only
```

## 使用与复跑

建议在 `http://localhost` 使用 `seed_student_04` 体验 Java 完整流程；
`seed_student_05`、`seed_student_06` 对应前端、运营。
新账号随机密码只存于本地忽略文件 `logs/seed-realistic-access.json`，不要提交或放进报告。
早期试导入账号可能使用该文件中的历史密码。

复跑方法见 [数据填充说明](../../docs/seed-realistic-data.md)。保留进度文件以复用原记录。
人工修改过的资料会保留，失败列表读取不会被当作空列表；失败步骤可以恢复，不会删改其他用户记录。
Git 交付来源目录、脚本和报告；运行数据库、上传文件和账号凭据保存在本机存储中。
