## 导入与幂等

扩容先执行了 `--dry-run` 和 7 项脚本测试，再运行：

```powershell
node scripts/seed-realistic-data.cjs --students 180 --activities 24
node scripts/seed-realistic-data.cjs --students 24 --activities 24
node scripts/seed-realistic-data.cjs --verify-only
node scripts/verify-seeded-data.cjs
node logs/seed-company-inspect.cjs
```

第一轮中有 1 个阶段报告请求遇到临时 AI 服务不可用；答案和会话已经保存，随后用相同输入重试成功。重试判断已修复，重复运行不会覆盖回答或重复生成已完成活动。

最终业务读取验证结果为：`failures=[]`；180 名学生、180 份简历、564 条匹配、24 个计划、232 个任务、24 个面试、34 个资料和 180 个个人收藏全部通过所有权检查。重复匹配保持相同 ID 和逐项结果；他人简历、计划、面试不可读取；个人收藏相互隔离。

## 企业和服务状态

24 个合成企业账号各自只能看到自己的教学投递，24 条投递和 24 条内部初筛任务均为 `COMPLETED`。15 个 Docker 容器保持 `healthy`，MySQL、MinIO 和 Redis 数据卷未重置。原有中国镜像配置和微服务端口保持不变。
