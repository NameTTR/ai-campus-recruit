# v3.10 Real RAG Corpus and Admin Knowledge Console

## Highlights

- Added a classpath RAG corpus at `backend/ai-service/src/main/resources/knowledge/campus-rag-corpus.json` with 12 campus recruitment documents covering Java backend interviews, three-VM deployment, RAG rules, MySQL, Redis, RocketMQ, RBAC, boundary testing, frontend review, and AI governance.
- `ai-service` now imports configured corpus resources on startup and updates existing system seed documents while preserving manually created admin documents.
- Added `GET /api/ai/knowledge/stats` for admin-visible document count, chunk count, category/source/role/tag counts, seed status, corpus version, and store mode.
- Admin UI now includes RAG corpus metrics, document filtering, document list, and manual document creation.

## Deployment

- Three-VM VM3 compose enables corpus seeding by default through `AI_KNOWLEDGE_SEED_ENABLED=true`.
- `AI_KNOWLEDGE_SEED_LOCATIONS` defaults to `classpath*:/knowledge/*.json`.
- `AI_KNOWLEDGE_CORPUS_VERSION` defaults to `v3.10-campus-rag-corpus`.
