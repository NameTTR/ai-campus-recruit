# v1.3 Regression and Deployment Acceptance Scripts

## Scope

- 新增 API smoke 脚本，覆盖关键业务接口。
- 保留 v1.0 的三机健康检查脚本，形成部署验收顺序：先健康检查，再业务 smoke。
- PowerShell 和 bash 两套脚本都支持自定义目标地址和超时时间。
- 脚本失败时返回非零 exit code，便于 CI 或人工验收。

## Files

- `scripts/check-api-smoke.ps1`
- `scripts/check-api-smoke.sh`
- `scripts/check-three-vm-health.ps1`
- `scripts/check-three-vm-health.sh`

## API Smoke Coverage

- `POST /api/auth/login`
- `GET /api/students/profile`
- `GET /api/jobs`
- `GET /api/ai/status`
- `POST /api/deliveries`
- `GET /api/deliveries/events`
- `GET /api/admin/dashboard`

v2.3 后，脚本会先分别登录 `student`、`company`、`admin` 获取 JWT，并对受保护 API 自动携带 `Authorization: Bearer <token>`。
只启动 `auth-service`、`user-service`、`gateway-service` 做本地鉴权 smoke 时，可使用 `-CoreOnly` / `--core-only`。

## Usage

Local or single-node gateway:

```powershell
.\scripts\check-api-smoke.ps1 -BaseUrl http://localhost:8080 -TimeoutSeconds 8
```

```bash
bash scripts/check-api-smoke.sh --base-url http://localhost:8080 --timeout 8
```

Three-VM deployment:

```powershell
.\scripts\check-three-vm-health.ps1 -EnvFile .\deploy\three-vm.env
.\scripts\check-api-smoke.ps1 -BaseUrl http://<VM1_IP>:8080
```

```bash
bash scripts/check-three-vm-health.sh --env-file deploy/three-vm.env
bash scripts/check-api-smoke.sh --base-url http://<VM1_IP>:8080
```
