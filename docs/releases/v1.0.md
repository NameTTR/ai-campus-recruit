# v1.0 Three-VM Health Check and Ops Baseline

## Scope

- 新增三虚拟机统一健康检查脚本，支持 Windows PowerShell 调用者和 Linux bash 调用者。
- 健康检查脚本读取 `deploy/three-vm.env` 或指定 env 文件，不输出密钥。
- 覆盖 VM1 前端、Gateway、Nacos，VM2 六个业务服务，VM3 `ai-service`、MySQL、Redis、MinIO、RocketMQ 基础端口或 HTTP 端点。
- 补齐部署文档中的健康检查、基础监控和日志排障步骤。
- 保持国内网络兼容说明，继续使用国内镜像源、阿里云 Maven 镜像和 npmmirror。

## Health Checks

PowerShell:

```powershell
.\scripts\check-three-vm-health.ps1 -EnvFile .\deploy\three-vm.env -TimeoutSeconds 5
```

bash:

```bash
bash scripts/check-three-vm-health.sh --env-file deploy/three-vm.env --timeout 5
```

检查范围：

| VM | Checks |
| --- | --- |
| VM1 | Frontend `/`、Frontend `/api/ai/status` 代理、Gateway `/actuator/health`、Gateway `/api/ai/status`、Nacos `/nacos/`、Nacos gRPC `9848` |
| VM2 | `auth-service`、`user-service`、`resume-service`、`job-service`、`match-service`、`delivery-service` 的 `/actuator/health` |
| VM3 | `ai-service` `/actuator/health`、`/api/ai/status`、MySQL `3306`、Redis `6379`、MinIO `/minio/health/ready`、MinIO Console `9001`、RocketMQ `9876`、`10911`、`10909` |

## Monitoring and Logging Baseline

v1.0 不新增重量级监控组件，先建立可复用的运维基线：

- 使用健康检查脚本作为部署后验收和故障定位入口。
- 使用 `docker compose ps` 检查容器状态。
- 使用 `docker compose logs --tail 100 <service>` 查看服务启动和运行日志。
- 使用 Spring Boot `/actuator/health` 作为微服务健康信号。
- 使用 MinIO `/minio/health/ready` 和基础 TCP 探测确认中间件可达性。

Prometheus、Grafana、集中日志采集可在后续版本接入，不影响 v1.0 的三机验收。
