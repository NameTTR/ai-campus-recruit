# v3.6 Release Notes

This release completes the requested operations and AI enhancement items 1-5.

## Completed

- Monitoring: added Prometheus, Grafana, node-exporter, and Sentinel Dashboard to the three-VM deployment. Prometheus, Grafana, and Sentinel run on VM1; all three VMs expose node-exporter metrics.
- CI/CD: expanded GitHub Actions to run backend tests, frontend tests/build/E2E smoke, monitoring render, security baseline, Compose validation, and Docker build smoke.
- Backup and restore: added VM3 MySQL, Redis, and MinIO backup/restore scripts with SSH-key based usage and destructive restore protection.
- Security hardening: added Nginx security headers, Gateway auth checks, default secret checks, runtime env tracking checks, and backup directory ignore rules.
- AI coach advice: added `POST /api/ai/coach/advice` for student career coaching with DashScope support and deterministic fallback.
