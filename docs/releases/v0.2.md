# v0.2 投递审核与状态看板

## 版本目标

补齐学生、企业、学校三端围绕岗位投递的审核闭环。学生投递岗位后，企业可以查看本企业投递并推进状态，学生端展示中文状态，学校端查看状态分布与待处理数量。

## 功能清单

- 学生端：投递记录状态显示为中文，覆盖已投递、已查看、面试中、已录用、未通过。
- 企业端：新增投递审核区，展示企业投递列表，支持更新为已查看、面试中、已录用、未通过。
- 学校端：新增待处理投递指标，展示投递状态分布和占比。
- 前端 API：新增公司投递列表、投递统计、投递状态更新的离线 fallback。
- 后端：`delivery-service` 提供企业投递列表和投递统计接口，`user-service` dashboard 返回投递状态字段。

## 新增接口

- `GET /api/deliveries/company?companyId=C001`：查询企业投递列表。
- `GET /api/deliveries/statistics`：查询投递总量、状态分布和待处理数量。
- `PUT /api/deliveries/{id}/status?status=INTERVIEW`：推进投递状态，继续支持 `VIEWED`、`INTERVIEW`、`OFFER`、`REJECTED`。
- `GET /api/admin/dashboard`：增强返回 `deliveryStatusCounts` 和 `pendingDeliveryCount`。

## 验收场景

- 学生登录后投递岗位，投递记录显示“已投递”。
- 企业登录后在投递审核区看到 `C001` 的投递列表，并可将记录推进到面试中、录用或拒绝。
- 学校就业办看板展示待处理投递数，并按状态展示分布。
- 后端服务未启动时，前端仍通过 fallback 数据完成三端演示。
