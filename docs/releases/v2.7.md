# v2.7 AI Observability and Intelligent Search

## Scope

- Added frontend API client types and methods for AI observability summary, recent AI call records, and intelligent search.
- Added deterministic frontend fallback data so local demo mode remains usable without a configured gateway or AI proxy.
- Added an admin sidebar module for AI observability and intelligent search.
- Added backend in-memory AI call observability records with prompt/response lengths, latency, fallback reason, and mock status.
- Added local intelligent search over demo recruitment knowledge plus runtime screening/interview records.
- Added gateway permission enforcement for admin-only AI observability APIs.
- Documented the v2.7 API contract and product requirements.

## API Contract

- `GET /api/ai/observability/summary` returns `ApiResponse<AiObservabilitySummary>`.
- `GET /api/ai/observability/calls?limit=20&provider=&success=` returns `ApiResponse<AiCallRecord[]>`.
- `POST /api/ai/search` accepts `{ query, role?, limit? }` and returns `ApiResponse<AiSearchResponse>`.
