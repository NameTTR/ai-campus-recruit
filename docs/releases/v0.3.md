# v0.3 AI 模拟面试教练

## 版本目标

在简历匹配和投递流程之后补充学生面试训练闭环。学生可针对目标岗位生成模拟面试题，提交回答并获得结构化反馈；后端不可用或未配置大模型 Key 时仍可完成演示。

## 功能清单

- 学生端：新增 AI 模拟面试面板，支持生成题目、选择题目、录入回答和查看反馈。
- 回答反馈：展示评分、优势、不足、改进建议和总结。
- 前端 API：新增面试问题与面试反馈调用，并提供确定性离线 fallback。
- 后端 AI 服务：新增面试题生成和反馈接口，沿用 DashScope 接入及失败降级策略。
- 测试：覆盖无 Key 时后端 mock 响应，以及前端离线面试流程数据。

## 新增接口

- `POST /api/ai/interview/questions`：输入学生、简历、岗位、目标角色和技能，返回多道 `InterviewQuestion`。
- `POST /api/ai/interview/feedback`：输入题目与学生回答，返回 `InterviewFeedback` 结构化反馈。

## 验收场景

- 学生完成岗位匹配或投递后，生成至少两道目标岗位模拟面试题。
- 学生选中题目、输入回答并提交后，页面展示评分、优势、不足和改进建议。
- 未设置 `DASHSCOPE_API_KEY` 时，后端反馈返回 `mocked=true`，接口仍可正常演示。
- 后端服务不可达时，前端使用 fallback 面试题和反馈完成同样的页面流程。
