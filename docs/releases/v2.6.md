# v2.6 Release Notes

## Theme

Prepare frontend API types and documentation for production-grade user accounts and fine-grained RBAC.

## Frontend API Scope

- Added account lifecycle types: `AccountStatus`, `PermissionCode`, `AccountSummary`, `AccountListQuery`, `CreateAccountRequest`, `ChangePasswordRequest`, and `CurrentPermissions`.
- Added account API client functions:
  - `listAccounts(query)`
  - `createAccount(payload)`
  - `updateAccountStatus(accountId, status)`
  - `changeAccountPassword(payload)`
  - `getCurrentPermissions()`
- Kept development fallback behavior: when no gateway or API base URL is configured, the frontend returns deterministic student, company, and admin demo accounts with role-based permission codes.

## API Contract

- `GET /api/admin/accounts`
- `POST /api/admin/accounts`
- `PUT /api/admin/accounts/{accountId}/status`
- `PUT /api/accounts/{accountId}/password`
- `GET /api/auth/permissions`

All responses continue to use `ApiResponse<T>`. Password APIs must never return plaintext passwords or password hashes.

## Documentation

- Updated `docs/requirements.md` with the v2.6 production user and RBAC requirement.
- Updated `docs/api.md` with endpoint contracts, request/response fields, permissions, and frontend fallback notes.

## Verification

- Suggested command: `cd frontend && npm run test:unit`.
