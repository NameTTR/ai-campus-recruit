# v1.4 Enterprise Screening Resume Parse Metadata

## Scope

- AI candidate screening now accepts resume parse metadata from the caller:
  - `resumeSourceFormat`
  - `resumeParseStatus`
  - `resumeParsedTextLength`
- `CandidateScreenResult` and `CandidateScreenRecord` return the same metadata so enterprise users can judge whether AI screening is based on extracted resume text.
- Screening prompt includes parse quality context and asks AI to flag insufficient resume text evidence when the resume is `UNPARSED` or `UNKNOWN`.
- MySQL schema for `ai_candidate_screen_record` includes the three metadata columns.
- Enterprise frontend shows compact parse tags in matching cards, delivery review cards or table rows when data exists, and screening history.
