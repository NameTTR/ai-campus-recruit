# v3.7 Boundary Validation

- Added `scripts/check-boundary-cases.ps1` for full deployed boundary validation across authentication, RBAC, trusted identity propagation, resume upload/error handling, delivery transitions, AI edge inputs, monitoring endpoints, and restore-script safety guards.
- Fixed unknown resume detail/analyze requests so they return `ApiResponse.fail("Resume not found")` instead of falling back to seeded demo data.
- Fixed unknown delivery status updates so they return `ApiResponse.fail("Delivery not found")` instead of updating the seeded demo delivery.
- Added service-local `ApiResponse` error wrapping for missing resume upload files, invalid delivery status values, malformed delivery JSON, and missing delivery parameters.
- Tightened gateway RBAC for student-owned AI endpoints: AI coach advice, resume rewrite, and career planning/history are no longer accessible to `COMPANY` users.

Verification:

```powershell
cd backend
mvn -s settings.xml.example -pl resume-service -am test
mvn -s settings.xml.example -pl delivery-service -am test
mvn -s settings.xml.example -pl gateway-service -am test
```
