# v2.8 Resume File and Data Loop

## Scope

- Added a student resume lifecycle module that links resume file metadata, parse status, AI diagnosis, delivery snapshots, and AI candidate-screening feedback.
- Added frontend API client support for `GET /api/ai/screenings/my?studentId=S001`.
- Documented the student-owned screening feedback contract and trusted identity behavior.

## Frontend

- New student navigation entry: `/student/lifecycle`.
- The lifecycle view reuses existing resume, delivery, and candidate-screening record data.
- Demo fallback remains deterministic when no gateway or AI proxy is configured.

## API Contract

- `GET /api/ai/screenings/my?studentId=S001`
- Response: `ApiResponse<CandidateScreenRecord[]>`
- `STUDENT` identity injected by Gateway overrides query `studentId`.
- `ADMIN` may query by `studentId`.
- `COMPANY` should continue using `/api/ai/candidates/screenings`.
