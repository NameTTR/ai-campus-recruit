# v0.4 AI Module Engineering

## Scope

- 新增 `GET /api/ai/status`，用于查看 AI provider、模型、配置状态、可用能力和降级原因。
- 将 AI 能力从单一调用类演进为“控制器 + 服务编排 + provider client”的结构，便于后续替换模型供应商或接入多模型路由。
- 面试题与面试反馈接口要求模型返回结构化 JSON，后端仍保留解析兜底和确定性 mock。

## API

- `GET /api/ai/status`
  - 返回 `AiModuleStatus`
  - 字段：`provider`、`model`、`configured`、`baseUrl`、`capabilities`、`fallbackReason`
  - 不返回 `DASHSCOPE_API_KEY`
- `POST /api/ai/analyze`
  - 保持兼容，用于简历、岗位和匹配分析
- `POST /api/ai/interview/questions`
  - 保持兼容，返回 3 道结构化面试题
- `POST /api/ai/interview/feedback`
  - 保持兼容，返回评分、优势、不足、建议和一句话总结
