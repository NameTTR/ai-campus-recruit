# v3.9 Persistent RAG and Step Load Smoke

## Scope

- Upgraded the RAG knowledge base from in-memory keyword retrieval to document persistence, chunking, local hash-vector embeddings, hybrid ranking, and cited answers.
- Added `POST /api/ai/knowledge/answer`, returning `KnowledgeAnswerResponse` with citations and deterministic fallback when external AI is disabled or unavailable.
- Added MySQL schema support for `ai_knowledge_document` and `ai_knowledge_chunk`.
- Added `AI_KNOWLEDGE_PERSISTENCE_ENABLED`, enabled by default in the three-VM compose file.
- Extended `scripts/run-load-smoke.ps1` to probe RAG answer assembly with `useAi=false`.
- Added `scripts/run-step-load-smoke.ps1` for stepped concurrency checks.

## RAG Runtime

- `POST /api/ai/knowledge/documents`: admin creates a knowledge document; `ai-service` stores the document and generated chunks.
- `POST /api/ai/knowledge/search`: retrieves ranked readable chunks using hash-vector cosine similarity plus lexical matching.
- `POST /api/ai/knowledge/answer`: retrieves top chunks, returns citations, and calls DashScope when `useAi=true` and `DASHSCOPE_API_KEY` is configured.
- Student/company Gateway identity overrides request-body role to avoid cross-role retrieval.

## Step Load Smoke

```powershell
.\scripts\run-step-load-smoke.ps1 `
  -BaseUrl http://192.168.6.130:8080 `
  -DemoPassword 123456 `
  -UserSteps 3,10,30,50 `
  -Iterations 3 `
  -TimeoutSeconds 15
```

The step script writes `reports/deploy/step-load-smoke-<timestamp>.md` and child `load-smoke-<timestamp>.md` reports. Demo passwords and bearer tokens are not written to reports.
