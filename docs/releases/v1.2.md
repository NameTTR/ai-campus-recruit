# v1.2 RocketMQ Delivery Events

## Scope

- `delivery-service` 新增投递事件发布器。
- 创建投递时生成 `DELIVERY_CREATED` 事件。
- 更新投递状态时生成 `DELIVERY_STATUS_CHANGED` 事件。
- RocketMQ 默认本地关闭，Docker Compose 和三机部署开启。
- RocketMQ 不可用时主流程降级，事件记录为 `FAILED`；未开启时记录为 `DISABLED`。
- 新增 `GET /api/deliveries/events` 查看最近事件，便于演示和排障。

## Configuration

- `DELIVERY_EVENTS_ROCKETMQ_ENABLED`
  - 本地默认：`false`
  - Docker Compose / 三机部署默认：`true`
- `ROCKETMQ_NAME_SERVER`
  - 单机 Compose：`rocketmq-namesrv:9876`
  - 三机 VM2：`${VM3_HOST}:9876`
- `DELIVERY_EVENTS_TOPIC`
  - 默认：`delivery-events`
- `DELIVERY_EVENTS_PRODUCER_GROUP`
  - 默认：`delivery-service-producer`

## API Impact

新增接口：

- `GET /api/deliveries/events`
  - 返回：`DeliveryEvent[]`
  - 字段：`eventId`、`eventType`、`deliveryId`、`studentId`、`resumeId`、`jobId`、`companyId`、`deliveryStatus`、`publishStatus`、`createdAt`

事件状态：

- `DISABLED`：RocketMQ 发布关闭。
- `SEND_OK`：RocketMQ 发布成功。
- `FAILED`：发布失败，投递主流程继续。
