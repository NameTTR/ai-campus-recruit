# v1.5 Delivery Resume Parse Snapshot

## Scope

- Student delivery creation now carries the current resume parse metadata:
  - `resumeSourceFormat`
  - `resumeParseStatus`
  - `resumeParsedTextLength`
- `DeliveryRecord` stores and returns the parse snapshot so company delivery review can show resume quality before screening.
- `DeliveryEvent` also includes the parse snapshot, preserving the same context for RocketMQ delivery events.
- Existing delivery callers remain compatible. Missing parse metadata defaults to `UNKNOWN`, `UNKNOWN`, and `0`.
- Company delivery review displays parse tags in both table and mobile card views.
