# v0.6 AI Candidate Screening

## Scope

- 新增后端 AI 候选人初筛接口，企业可基于投递、简历摘要、项目经历和岗位要求获得结构化筛选建议。
- 企业端投递审核列表新增 `AI 筛选` 操作，生成筛选分数、推荐结论、优势、风险、面试追问和下一步动作。
- DashScope 能力列表新增 `candidate-screening`。
- 未配置 `DASHSCOPE_API_KEY` 或模型调用失败时，返回确定性 mock 结果，保证演示流程可用。

## API

- `POST /api/ai/candidates/screen`
  - 请求体：`CandidateScreenRequest`
  - 返回：`CandidateScreenResult`
  - 字段：`deliveryId`、`studentId`、`jobId`、`score`、`recommendation`、`strengths`、`risks`、`interviewQuestions`、`nextActions`、`mocked`
  - 真实模型调用要求返回 JSON；后端解析成功时 `mocked=false`

## Verification

```powershell
cd backend
mvn -s settings.xml.example -pl common,ai-service -am test

cd ../frontend
npm run test:unit
npm run build
```

Runtime validation:

- Start `ai-service` on a free local port, for example `8116`.
- Start Vite with `VITE_AI_PROXY_TARGET=http://127.0.0.1:8116`.
- Login as `company`, open 企业端, click `AI 筛选`, and confirm the screening card renders without console errors.
