# v3.11 RAG Bulk Ingestion and Milvus

## Scope

- Added admin RAG file upload for `.txt`, `.md`, `.pdf`, `.doc`, and `.docx`.
- Added async ingestion job tracking with SHA-256 duplicate detection.
- Added MinIO storage for original knowledge files when enabled.
- Added Milvus REST vector index integration with local retrieval fallback.
- Added admin UI panels for vector status, file upload, and ingestion jobs.
- Updated three-VM deployment to place Milvus on VM3.

## Services

- `ai-service`: port `8106`, health `/actuator/health`, OpenAPI `/swagger-ui.html`.
- New API endpoints:
  - `POST /api/ai/knowledge/files`
  - `GET /api/ai/knowledge/ingestions`
  - `GET /api/ai/knowledge/vector/status`

## Deployment

- VM3 now runs MySQL, Redis, MinIO, RocketMQ, Milvus, and `ai-service`.
- Docker images use China-accessible mirrors in `deploy/docker-compose.vm3.yml`.
- Default vector settings are controlled by:
  - `AI_KNOWLEDGE_VECTOR_ENABLED=true`
  - `MILVUS_ENDPOINT=http://milvus-standalone:19530`
  - `MILVUS_COLLECTION=campus_knowledge_chunks`
  - `MILVUS_DIMENSION=96`

## Verification

- Backend: `cd backend; mvn -s settings.xml.example -pl common,ai-service,gateway-service -am test`
- Frontend: `cd frontend; npm run test:unit -- --run`
- Type check: `cd frontend; npx vue-tsc --noEmit`
- Compose: `docker compose -f deploy/docker-compose.vm3.yml --env-file deploy/three-vm.env.example config --quiet`
