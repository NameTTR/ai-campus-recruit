# v0.5 AI Interview Records

## Scope

- 学生端展示 AI 模块状态，区分真实模型在线和离线演示降级。
- 提交模拟面试回答后，后端自动保存本次题目、回答、评分、建议和生成时间。
- 学生端新增面试记录区，支持查看历史评分、模式、总结、题目、回答和建议。

## API

- `GET /api/ai/interview/records?studentId=S001`
  - 返回 `InterviewRecord[]`
  - 按 `createdAt` 倒序
  - MVP 使用内存存储，服务重启后清空
