# 学生工作台精简验证

验证日期：2026-10-05。环境：Windows、真实 Docker 服务、Chromium。

## 页面调整

- 移除五个学生模块的英文装饰标题、重复介绍和初始空状态插画。
- 简历制作步骤和刷新按钮合并为工具栏，保留编辑、预览和下载入口。
- 岗位详情按内容高度显示，列表保持可滚动；匹配控件保留明确字段标签。
- 学习任务排在历史版本和复盘之前；历史、成果详情默认折叠，可展开操作。
- 已完成任务不再显示无效按钮；未完成任务按状态显示开始或暂停。
- 知识库首屏直接显示模式和搜索，不预填示例词，不展示空统计。
- 无学习计划或面试会话时直接显示创建控件。
- 学生侧栏移除宣传卡、标语和装饰页脚；账户、导航和退出入口保留。
- 修复 Windows 滚动条使 320px 页面出现横向滚动的问题。
- 修复简历 PDF 普通预览在滚轮到达边界后截留页面滚动的问题；展开预览仍保持独立滚动，关闭、后退或组件卸载都会恢复页面滚动。

## 复现与修复依据

手机 390px 下，旧学习页任务区从约 1707px 才开始，前面主要是版本、复盘和重复摘要；调整后任务区从约 383px 开始。

桌面岗位详情旧布局被拉伸至约 564px，内容高度远小于容器。修复后按内容显示，验证样例约 182–206px。

知识库旧首屏先展示空统计、英文标题、重复中文标题、说明和空状态插画；修复后搜索框直接出现在首屏。

320px 下旧 `body` 最小宽度为 320px，Windows 滚动条占用空间后可用宽度为 305px，造成横向滚动。手机断点取消该最小宽度，验证比较页面实际 `clientWidth` 与 `scrollWidth`。

滚动故障在 1440x720 的真实简历草稿复现：普通 PDF 使用 `overscroll-behavior: contain`，鼠标位于已适应整页的预览中央时，两次滚轮都使外页停在 0px，而外页实际还有约 477px 内容。修复后相同操作可到达底部。适应宽度模式先正常滚动 PDF 内部约 200px，到达 PDF 边界后继续滚动外页；390px 手机在预览中央触摸滑动后外页从 0px 移动到约 593px。

Playwright 对简历、岗位匹配、学习路径、模拟面试、知识库分别检查 1440、1024、390、320px，共 20 组布局；检查页面宽度、首屏位置、折叠状态，并保存截图。

新增真实滚动回归覆盖 1440x720、390x844 和 320x900：桌面鼠标滚轮、移动端触摸滑动均能到达页面底部并返回顶部，侧栏关闭后滚动仍可用；正文没有残留 `overflow: hidden` 或不可达底部。简历预览还检查了普通模式的滚动链、全屏模式的滚动隔离，以及 Escape、页面后退和卸载后的滚动恢复。
