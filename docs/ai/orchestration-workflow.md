# AI 调度开发流程

## 角色

- 主控 Codex：负责需求澄清、版本规划、任务拆分、验收、修复集成问题、提交和推送。
- 开发 Codex worker：负责按明确范围实现功能、补测试、运行局部验证并汇报修改文件。

## 标准流程

1. 主控 Codex 定义版本目标、验收场景和 worker 写入范围。
2. 开发 Codex worker 修改代码和文档，不处理 GitHub 推送。
3. 主控 Codex 检查 diff，运行完整验证。
4. 如有 bug，主控 Codex 可直接修复集成问题，或再次派发给 worker。
5. 主控 Codex 提交并推送到 GitHub。
